Madli has no proprietary glyph set; the system standardises on Lucide, loaded per-icon from CDN and masked so it inherits colour.

```jsx
<Icon name="map-pin" size={18} color="var(--teal-500)" />
```

Sizes used in product: 14 (inline), 17–18 (buttons, fields), 21 (tab bar), 26 (empty states). Never mix another icon family into a Madli surface.
