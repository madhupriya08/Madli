Renders the supplied Madli artwork. Do not recreate the mark in type or SVG.

```jsx
<Logo variant="wordmark" height={26} assetBase="../../assets" />
```

`mark` = spoon/fruit circle only (min 24px). `wordmark` = "Madli". `full` = mark + wordmark + tagline on cream. Clear space around the mark equals the height of the "M".
